# 🚀 پروژه الگوریتم زمان‌بندی Stride Scheduling

## 📌 معرفی پروژه

این پروژه با زبان برنامه‌نویسی **Python** پیاده‌سازی شده و هدف آن شبیه‌سازی الگوریتم زمان‌بندی پردازنده با روش **Stride Scheduling** است.

در سیستم‌عامل، چندین فرایند ممکن است به‌صورت هم‌زمان به پردازنده نیاز داشته باشند. الگوریتم‌های زمان‌بندی مشخص می‌کنند که پردازنده در هر لحظه به کدام فرایند اختصاص داده شود.

الگوریتم Stride Scheduling با استفاده از مفاهیم **Ticket، Stride و Pass**، سهم نسبی هر فرایند از پردازنده را مدیریت می‌کند.

## 🎯 اهداف پروژه

- پیاده‌سازی الگوریتم Stride Scheduling با پایتون
- بررسی نحوه انتخاب فرایندهای آماده برای اجرا
- محاسبه زمان شروع و پایان هر فرایند
- محاسبه معیارهای زمان‌بندی و عملکرد فرایندها
- نمایش ترتیب اجرای فرایندها در قالب نمودار گانت (Gantt Chart)
- محاسبه میانگین معیارهای زمان‌بندی

## 🧠 مفاهیم اصلی الگوریتم

### 1. فرایند (Process)

فرایند برنامه‌ای در حال اجرا است که برای انجام وظایف خود به پردازنده نیاز دارد. در این پروژه، هر فرایند با مشخصات زیر تعریف می‌شود:

- **PID:** شناسه فرایند
- **Arrival Time:** زمان ورود فرایند به سیستم
- **Burst Time:** مدت‌زمان موردنیاز برای اجرای فرایند
- **Tickets:** تعداد بلیت‌های اختصاص‌یافته به فرایند

### 2. بلیت (Ticket)

تعداد بلیت‌ها نشان‌دهنده سهم نسبی هر فرایند از پردازنده است. هرچه تعداد بلیت‌های یک فرایند بیشتر باشد، در شرایط یکسان سهم بیشتری از پردازنده دریافت می‌کند.

### 3. گام (Stride)

مقدار Stride از تقسیم یک عدد ثابت به نام `BIG_STRIDE` بر تعداد بلیت‌های فرایند محاسبه می‌شود:

```text
Stride = BIG_STRIDE / Tickets
```

بنابراین، فرایندهایی که بلیت بیشتری دارند، مقدار Stride کمتری خواهند داشت.

### 4. مقدار Pass

مقدار Pass نشان‌دهنده میزان پیشرفت نوبت‌بندی هر فرایند است. در هر مرحله، از میان فرایندهای آماده، فرایندی که مقدار Pass کمتری دارد انتخاب می‌شود.

پس از اجرای فرایند، مقدار Pass آن به‌اندازه Stride افزایش پیدا می‌کند.

## 🧮 فرمول‌های محاسباتی

### زمان بازگشت (Turnaround Time)

```text
Turnaround Time = Finish Time - Arrival Time
```

### زمان انتظار (Waiting Time)

```text
Waiting Time = Turnaround Time - Burst Time
```

### زمان پاسخ (Response Time)

```text
Response Time = Start Time - Arrival Time
```

### میانگین زمان انتظار

```text
Average Waiting Time = Sum of Waiting Times / Number of Processes
```

### میانگین زمان بازگشت

```text
Average Turnaround Time = Sum of Turnaround Times / Number of Processes
```

### میانگین زمان پاسخ

```text
Average Response Time = Sum of Response Times / Number of Processes
```
